## Опис проєкту
Консольний застосунок C# (.NET SDK), що демонструє базові принципи об'єктно-орієнтованого програмування (інкапсуляція, класи, об'єкти, властивості, конструктори).

### Структура класу Computer:
- **Приватні поля:** `cpu` (string), `ram` (int)
- **Публічна властивість:** `Storage` (int)
- **Метод:** `RunBenchmark()` — розраховує та виводить тестування продуктивності комп'ютера.
